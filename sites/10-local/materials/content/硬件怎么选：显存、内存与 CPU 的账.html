硬件怎么选：显存、内存与 CPU 的账

上一篇讲了「为什么需要本地部署」，相信你已经心痒痒，想看看自己的电脑能不能跑。这一篇我们把账算清楚：跑大模型到底需要什么硬件？显存、内存、CPU 各自扮演什么角色？

别怕，这一篇不要求你懂电路。我们从一个「厨房比喻」开始，把三大件的关系讲得明明白白。

1. 先认识三大件：显存是「操作台」，内存是「备菜区」，CPU 是「厨师」

先给没有硬件基础的读者建立一个直觉。

跑大模型（推理，也就是「让模型回答问题」这件事），主要涉及电脑的三个部件：

部件 通俗类比 在这件事里的角色
显卡（GPU） 后厨的「大厨」 负责最重的并行计算，把模型「算」起来
显存（VRAM） 大厨的「操作台」 模型本体必须放在这里，才能被快速调用
内存（RAM） 后厨的「备菜区」 临时存各种数据，也会放一部分模型（当显存不够时）
CPU 后厨的「总管」 协调调度；显存不够时它亲自下厨（虽然慢）

关键结论提前说：跑大模型的瓶颈，几乎永远是「显存」。

为什么？因为模型在推理前，要把全部权重（也就是「模型大脑里的所有参数」）加载到一个地方，供计算单元随时读取。这个「随手能拿到」的地方就是显存。操作台只有那么大，放不下整个模型，厨师就做不了这道菜。

2. 模型有多大？先看懂参数与精度的关系

2.1 什么是「7B」「13B」「70B」？

B 是 Billion（十亿）的缩写。7B 模型 = 70 亿个参数。

参数是什么？可以把模型想象成一本超级厚的「工具书」，参数就是书里的每一个「知识点/判断标准」。参数越多，书越厚，懂的事情越多，但也越占地方。

常见规模划分：

  • 小模型（0.5B～4B）：跑得飞快，手机都能跑，但能力有限，适合简单任务；
  • 中型模型（7B～14B）：本地玩家的甜点区，效果好、硬件要求适中；
  • 大模型（32B～72B）：能力强很多，但需要好显卡或大内存；
  • 超大模型（100B+）：基本告别个人电脑，那是云端的领域。

2.2 什么是 FP16、FP32？——精度的账

模型参数存到电脑里，需要一种「数字表示法」，最常见的有：

  • FP32（单精度，32 位）：每个参数占 4 字节，最精确，最占空间；
  • FP16（半精度，16 位）：每个参数占 2 字节，精度够用，占一半空间——这是本地推理最常见的基准；
  • INT8 / INT4（量化，8 位 / 4 位整数）：每个参数占 1 / 0.5 字节，体积更小、速度更快，但精度打折。这就是第 4 篇 content/模型格式与量化：GGUF 与 Q4/Q8.md 要讲的内容。

显存需求的估算公式（超简单）：

所需显存 ≈ 参数数量 × 每个参数占用的字节数

例如 7B 模型，用 FP16（2 字节）：

70 亿 × 2 字节 = 140 亿字节 ≈ 14 GB

看，这就是上一篇提到「7B 模型约需 14GB」的来源。

4. 推理 vs 训练：为什么普通人只需要考虑「推理」

这里必须澄清一个常见误区。很多人一听「跑大模型」就以为要烧几块几十万的显卡。其实那是训练（training）的事。

  • 训练：让模型从零学知识，需要海量数据、超长周期，是 AI 公司和高校的事。一次训练耗电抵一个小城市的日常用电，普通人不用碰。
  • 微调（fine-tuning）：在训练好的模型基础上「补课」，让它学你的风格、你的业务。对硬件要求中等（可量化，入门级显卡也能做）。
  • 推理（inference）：模型已经训练好，你只是在「用」它——输入问题、得到回答。本地部署 99% 的场景是推理，推理对显存的要求远低于训练，一块家用显卡就够。

所以记住：我们本地部署，主要干的是「推理」这件事，别被「训练要烧钱」吓退。

5. 没有好显卡怎么办？CPU 方案完全可行

如果你的电脑没有独显，或者只有 4GB、8GB 显存的入门卡，先别灰心。三个现实可行的方案：

方案一：纯 CPU 跑小模型（0.5B～3B）

大模型的推理原理是大量矩阵乘法，天生适合 GPU 的并行计算，CPU 也能算，就是慢——但慢不代表不可用。

  • 0.5B～1.5B 的小模型在 CPU 上跑，每秒能出 10～20 个字，基本可用；
  • 7B 模型在 CPU 上跑，每秒可能只有 1～3 个字，能用来聊天但很煎熬；
  • 内存建议 16GB 起步，32GB 更舒服。

方案二：CPU + 内存「混合跑」（推荐入门）

这就是 llama.cpp / Ollama 这类工具的重要能力（见第 6 篇 content/推理引擎对比：llama.cpp、vLLM 与 Ollama.md）：把模型的一部分放进显存，剩下的放在内存里，让 GPU 和 CPU 协同工作。

  • 你有 8GB 显存 + 16GB 内存 → 可以跑 7B 量化模型，速度比纯 CPU 快不少；
  • 你有 12GB 显存 + 32GB 内存 → 14B 量化模型也能跑，效果明显上一个台阶。

方案三：内存超大 + 纯 CPU 跑中大型模型

如果你有一台 64GB 内存的机器（很多办公机、Mac 高配其实是这个量级），直接 CPU 跑 32B 的量化模型也行——速度慢，但效果很好，适合「不赶时间、要质量」的场景（比如批量写报告、分析长文档）。

Mac 用户的特别提醒：Apple Silicon（M 系列芯片）的 Mac，其「统一内存」（Unified Memory）既能当显存又能当内存，Ollama 可以直接用内存跑大模型。一台 16GB 的 M 系列 Mac 跑 7B 模型非常流畅，这是「没显卡」人群里体验最好的一种。

7. 其他几个容易踩的坑

7.1 笔记本显卡 vs 台式机显卡

笔记本的显卡虽然型号也叫 RTX 4060，但功耗墙更低（性能释放约 60%～80%），且显存通常比台式机少。买之前先查清楚你笔记本的真实显存。

7.2 「共享显存」不是真显存

很多显卡广告说「8GB 显存 + 16GB 共享显存」，那个「共享显存」是借用内存的，速度差一个数量级。判断标准只看独立显存（dedicated VRAM）多少。

7.3 硬盘空间也别忘了

模型文件动辄 4～40GB（见第 4 篇的量化体积表）。下载前确认 C 盘或模型存放盘有足够空间，SSD（固态硬盘）加载模型比机械硬盘快得多，强烈建议模型放 SSD。

7.4 电源与散热

桌面高端显卡满载功耗 200W+，电源瓦数要够，机箱散热要好。长期满载导致过热降频，速度会打折扣。

8. 怎么快速查看自己电脑的配置？

你不需要装任何第三方软件，用系统自带工具就能查到最关键的三样：显存、内存、CPU。

Windows 用户：

  1. 按 Win + R，输入 dxdiag 回车，打开「DirectX 诊断工具」；
  2. 看「显示」标签页：上面有显卡型号，下面「显示内存 (VRAM)」就是显存大小；
  3. 看「系统」标签页：有内存大小和 CPU 型号。

macOS 用户：点左上角苹果图标 →「关于本机」，直接看到芯片型号（如 M3）和内存大小。Apple Silicon 的统一内存就是可用的「显存」，比如 16GB 的 M3 大约等价于「16GB 显存」的体验。

Linux 用户：终端执行：

# 查看显卡与显存
nvidia-smi

# 查看内存与 CPU
free -h
lscpu

查到结果后，对着第 6 节「我的电脑能跑什么」的表格对号入座，就知道自己该从哪个模型起步了。

如果你确定要为此掏钱，这里给三档「闭眼买」的方案（价格为 2025 年左右的参考区间，仅供参考）：

档位 大致预算 配置要点 能跑什么
入门 0 元 就用现有电脑 + CPU 跑小模型 1.5B～3B，聊天级
实用 2000～4000 元 加一张 12GB 显存的显卡（如 RTX 3060 12G 一类的甜点卡）+ 32GB 内存 7B～14B 量化模型，流畅

几点省钱建议：

  1. 二手显卡是本地玩家的好朋友。本地推理不吃「最新架构」的红利，上一代的中高端卡性能完全够用，二手价能省三成以上；
  2. 内存 32GB 是甜点：16GB 内存跑 7B 会比较局促，32GB 基本无痛；64GB 则直接解锁 CPU 跑中大型模型的玩法；
  3. 固态硬盘必须：模型加载速度、系统流畅度都靠它，千万别在这上面省；
  4. 先软件后硬件：先用现有电脑跑通流程（第 3 篇），确定「真的需要」再买卡——避免冲动消费。

9. 常见硬件问答

9.1 「笔记本能跑大模型吗？」

能，但有前提。关键是看独立显存：8GB 显存的笔记本跑 7B 量化模型没问题；只有核显（共享内存）的笔记本只能跑 1.5B～3B 小模型。另外注意散热——笔记本跑大模型发热大，长时间满载会降频变慢。

9.2 「内存和显存到底什么关系？」

可以这样理解：显存是显卡自带的高速「台面」，内存是电脑的「仓库」。模型要跑得快，就得整体放在台面上（显存）；台面不够，部分放仓库（内存），让 CPU 和 GPU 配合搬运。仓库越大，能「挤」的模型越大，但搬运本身要花时间，所以速度会降。

9.3 「为什么我的 8GB 显存显卡跑 7B 还是报错？」

因为显存还要装 KV cache（上下文缓存）和其他临时数据，不是只有模型本身。8GB 显存跑 7B 的 Q4 版本刚刚好，但一旦上下文拉长（比如长文档总结），KV cache 就把显存吃满了。对策是缩短上下文或降量化（第 9 篇 content/性能调优：并发、批处理与显存优化.md 会详细讲）。

9.4 「跑模型和玩游戏，对显卡的要求一样吗？」

不完全一样。游戏看重「峰值算力」和「帧数」，大模型推理看重「显存容量」和「显存带宽」。所以一张「游戏表现一般但显存大、带宽宽」的显卡，跑模型可能反而比旗舰游戏卡更实用——选卡时优先盯显存容量，别只看算力。

9.5 「显存带宽重要吗？」

非常重要，是仅次于容量的第二个指标。模型推理时，GPU 需要高速读取权重，带宽越低越「卡顿」。这也是为什么高端卡跑模型明显更快——不只是算力强，带宽也宽。预算允许时，选带宽高的卡。

10. 本章小结

这一篇的「账」可以总结成三句话：

  1. 显存是第一瓶颈：模型必须装进显存才能快跑，显存 = 参数 × 精度；
  2. 量化是把钥匙：FP16 的 14GB 需求，量化成 Q4 只要约 4.5GB，普通人也能上车；
  3. 没显卡也能玩：CPU + 小模型慢速可用，M 系列 Mac 更是低门槛方案。
