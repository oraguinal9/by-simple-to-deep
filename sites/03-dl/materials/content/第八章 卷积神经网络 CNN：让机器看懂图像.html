第八章 卷积神经网络 CNN：让机器看懂图像

本章目标：理解卷积在做什么、为什么它比全连接层适合图像，以及 CNN 的经典结构。即使你只关心大模型，CNN 的思想（局部性、权重共享）也会在多模态里反复出现。

8.1 全连接层处理图像有多浪费

一张普通的彩色照片：224 × 224 × 3（宽 × 高 × RGB 三通道）= 150,528 个数字。

如果直接接一个 1000 个神经元的全连接层：

参数量 = 150,528 × 1000 = 1.5 亿个    ← 仅仅第一层！

三个致命问题：

  1. 参数爆炸：一层就 1.5 亿参数，必然过拟合，显存也扛不住。
  2. 丢失空间结构：全连接要求把图像"拉平"成一维向量，相邻像素的位置关系被彻底破坏。左上角和右下角的像素在模型眼里同等相邻。
  3. 不具备平移不变性：猫在左上角学到的特征，换到右下角就完全不认识了，必须重新学一遍。

CNN 用三个思想一次性解决了这三个问题。

8.2 核心思想一：局部连接

认知起点：识别一只眼睛，只需要看眼睛周围那一小块像素，不需要看整张图。

所以：每个神经元只连接输入的一小块区域（比如 3×3），而不是全部像素。

全连接：每个神经元看 150,528 个像素
卷积  ：每个神经元只看 3×3×3 = 27 个像素

参数量瞬间从"亿"降到"十"这个量级。

8.3 核心思想二：权重共享

认知起点：检测"竖直边缘"这件事，在图像左上角和右下角的做法完全一样。

所以：同一个 3×3 的小窗口（卷积核）在整张图上滑动，处处使用同一组权重。

这就是"卷积"这个名字的由来——一个小窗口扫过整张图。

图像 5×5                卷积核 3×3
┌─────────────┐         ┌───────┐
│ ▣ ▣ ▣ · · │         │ w w w │
│ ▣ ▣ ▣ · · │  ⊛      │ w w w │   →  输出一个数
│ ▣ ▣ ▣ · · │         │ w w w │
│ · · · · · │         └───────┘
│ · · · · · │      核在图上从左到右、
└─────────────┘      从上到下滑动

每滑到一个位置，就把窗口内 9 个像素 × 对应 9 个权重，加起来（还是加权求和！第四章的老朋友），得到输出图上的一个点。

收益：

  • 参数量与图像尺寸完全无关：3×3 的核永远只有 9 个参数，处理 224×224 或 4096×4096 都一样
  • 天然平移不变：同一个核扫全图，猫在哪都能被检出

8.4 卷积到底算了什么？

举个具体例子。这是一个竖直边缘检测核（Sobel 算子的简化版）：

 1  0  −1
 1  0  −1
 1  0  −1

它在做什么？用左边三个像素减去右边三个像素。

  • 如果窗口内左右亮度差不多（平坦区域）→ 结果 ≈ 0
  • 如果左边亮、右边暗（一条竖边）→ 结果是很大的正数
  • 如果左边暗、右边亮 → 很大的负数

所以这个核扫过全图后，输出图上竖直边缘的位置会亮起来。这张输出图叫特征图（Feature Map）。

import numpy as np

img = np.array([                # 左半亮(10)，右半暗(0)，中间有条竖边
    [10,10,10, 0, 0],
    [10,10,10, 0, 0],
    [10,10,10, 0, 0],
    [10,10,10, 0, 0],
    [10,10,10, 0, 0],
], dtype=float)

kernel = np.array([[1,0,-1],[1,0,-1],[1,0,-1]], dtype=float)

H, W = img.shape
kh, kw = kernel.shape
out = np.zeros((H-kh+1, W-kw+1))
for i in range(out.shape[0]):
    for j in range(out.shape[1]):
        patch = img[i:i+kh, j:j+kw]      # 取出 3×3 窗口
        out[i, j] = (patch * kernel).sum()  # 逐元素相乘再求和
print(out)
# [[ 0. 30. 30.]      ← 第2、3列数值大，正好是边缘所在位置
#  [ 0. 30. 30.]
#  [ 0. 30. 30.]]

关键区别：传统图像处理里，这些核是人工设计的（Sobel、Laplacian 等）。 在 CNN 里，核里的 9 个数字是参数，靠梯度下降自动学出来的——模型自己决定该检测什么特征。

8.5 通道、步长、填充：三个必懂参数

通道（Channel）

一个核只能检测一种特征。要同时检测边缘、纹理、颜色块……就并排放很多个核。

  • 输入通道数：彩色图是 3（RGB）
  • 输出通道数：你放了多少个核，就有多少张特征图

一个卷积层的参数量：

参数量 = 核高 × 核宽 × 输入通道 × 输出通道 + 输出通道(偏置)

例：3×3 核，输入 3 通道，输出 64 通道 → 3×3×3×64 + 64 = 1792 个参数。 对比一下开头全连接层的 1.5 亿——省了将近 10 万倍。

步长（Stride）

核每次滑动几格。

  • stride=1：一格一格滑，输出尺寸≈输入
  • stride=2：跳着滑，输出尺寸减半，常用来下采样

填充（Padding）

在图像四周补一圈 0。

  • 不填充：5×5 图用 3×3 核 → 输出 3×3，每卷一次就缩小一圈
  • 填充 1 圈（padding=1）：输出仍是 5×5，尺寸不变

输出尺寸公式：

输出 = (输入 + 2×padding − 核大小) / stride + 1

💡 实践中最常见的配置是 3×3 核 + padding=1 + stride=1，作用是"提取特征但不改变尺寸"。需要缩小尺寸时用 stride=2 或池化层。

8.6 池化层：压缩信息

最大池化（Max Pooling）：在每个 2×2 区域里只保留最大值。

 1  3 │ 2  4          最大池化 2×2
 5  2 │ 1  0     →     5  4
──────┼──────          8  7
 8  1 │ 3  7
 4  6 │ 2  5

作用：

  • 尺寸减半，计算量降到 1/4
  • 提供一点平移容忍度：物体挪动几个像素，最大值往往不变
  • 扩大感受野：后面的层能"看到"原图更大的范围

📌 现代架构（如 ResNet）中，池化层用得越来越少，更多用 stride=2 的卷积来下采样——因为那样是可学习的。但理解池化仍然重要。

8.7 一个完整的 CNN 长什么样

经典结构就是一个"卷积 + 激活 + 池化"的三明治，重复几次，最后接全连接分类：

输入图 224×224×3
   ↓ Conv 3×3, 64 通道 + ReLU
   ↓ Conv 3×3, 64 通道 + ReLU
   ↓ MaxPool 2×2                  → 112×112×64
   ↓ Conv 3×3, 128 通道 + ReLU
   ↓ MaxPool 2×2                  → 56×56×128
   ↓ ...（继续加深，通道数翻倍、尺寸减半）
   ↓ 展平 Flatten
   ↓ 全连接 + Dropout
   ↓ 全连接 → 1000 类
   ↓ Softmax

通用规律：越往后，空间尺寸越小，通道数越多。

直观理解：从"高分辨率的低级信息（像素）"逐步变成"低分辨率的高级语义（这是猫脸）"。

import torch.nn as nn

model = nn.Sequential(
    nn.Conv2d(3, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),   # 32×32 → 16×16
    nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # 16×16 → 8×8
    nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2), # 8×8 → 4×4
    nn.Flatten(),
    nn.Linear(128*4*4, 256), nn.ReLU(), nn.Dropout(0.5),
    nn.Linear(256, 10),
)

这是一个可以在 CIFAR-10（10 类小图分类）上跑到 80% 以上准确率的网络。

8.8 里程碑架构一览

年份 模型 关键贡献

8.9 CNN 与 Transformer 的关系

你可能会问：既然现在都是 Transformer 的天下，还学 CNN 干嘛？

三个理由：

  1. CNN 的两大思想被继承了。ViT 把图像切成 16×16 的小块（patch），本质上就是一次大步长卷积；"局部性"和"权重共享"的思路无处不在。
  2. 实际工程里 CNN 仍是主力。小数据集、边缘设备、实时检测（YOLO 系列）等场景，CNN 又快又准，性价比远高于 ViT。
  3. 多模态大模型的视觉编码器很多仍基于 CNN 或 CNN-Transformer 混合结构。
CNN Transformer
归纳偏置 强（局部性、平移不变） 弱
小数据表现 好 差（需要大量数据预训练）
大数据表现 一般 更好
感受野 逐层扩大 第一层就是全局
计算复杂度 与像素数线性 与像素数平方

8.10 本章小结

  • 全连接处理图像有三宗罪：参数爆炸、丢失空间结构、无平移不变性
  • CNN 的三板斧：局部连接 + 权重共享 + 池化下采样
  • 卷积 = 小窗口滑过全图做加权求和，核里的数字是学出来的
  • 关键参数：通道数（检测多少种特征）、步长（缩放）、填充（保持尺寸）
  • 通用规律：越深，尺寸越小，通道越多——从像素走向语义
  • ResNet 的残差连接是深层网络的关键，Transformer 也在用
  • CNN 归纳偏置强，小数据场景仍优于 Transformer
