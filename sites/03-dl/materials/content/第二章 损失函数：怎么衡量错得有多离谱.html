第二章 损失函数：怎么衡量"错得有多离谱"

本章目标：理解损失函数（Loss Function）是什么、为什么必须有它、以及常见的两把尺子（MSE 与交叉熵）分别用在哪。

2.1 先问一个问题：怎么知道模型好不好？

回到上一章的房价模型。假设有两个人给出了不同的参数：

小明的模型 小红的模型
参数 w=3.1, b=0 w=2.8, b=25

哪个更好？光看参数看不出来，得拿数据试：

面积 真实价 小明预测 小明误差 小红预测 小红误差
60 186 186 0 193 +7
90 281 279 −2 277 −4
120 377 372 −5 361 −16

直觉上小明更好。但"直觉"不能写进程序，我们需要一个具体的数字来代表"总体错得有多离谱"。

这个数字就叫损失（Loss）。

2.2 第一次尝试：直接把误差加起来？

最朴素的想法：把所有误差加起来。

  • 小明：0 + (−2) + (−5) = −7
  • 小红：7 + (−4) + (−16) = −13

看起来能用？不行，有个致命问题：正负会互相抵消。

假设有个模型，一个样本预测高了 100 万，另一个低了 100 万，误差之和 = 0，看起来"完美"，实际上错得离谱。

所以必须先把误差变成非负数。有两个常见做法：

  1. 取绝对值 → 平均绝对误差 MAE
  2. 取平方 → 均方误差 MSE ⭐ 最常用

2.3 MSE：回归问题的标准尺子

均方误差（Mean Squared Error）：

MSE = (1/n) × Σ (yᵢ - ŷᵢ)²

翻译成人话：每个样本的误差先平方，再全部加起来，最后除以样本数取平均。

算一下上面的例子：

  • 小明：(0² + 2² + 5²) / 3 = (0+4+25)/3 = 9.67
  • 小红：(7² + 4² + 16²) / 3 = (49+16+256)/3 = 107

损失越小越好，所以小明的模型明显更优。

import numpy as np

y_true = np.array([186, 281, 377])
y_ming = np.array([186, 279, 372])
y_hong = np.array([193, 277, 361])

def mse(y, yhat):
    return np.mean((y - yhat) ** 2)

print(mse(y_true, y_ming))   # 9.67
print(mse(y_true, y_hong))   # 107.0

为什么用平方而不用绝对值？

三个理由，按重要性排序：

  1. 重罚大错。误差 10 平方后是 100，误差 1 平方后是 1。平方会让"离谱的大错"在损失里占绝对主导，逼着模型优先修正大错。
  2. 处处可导。绝对值函数在 0 点是个尖角，导数不存在；平方函数光滑可导。这一点极其重要——第三章你会看到，整个训练过程都建立在"求导"上。
  3. 数学性质好。MSE 对应正态分布假设下的最大似然估计，理论上站得住脚。

⚠️ 副作用：MSE 对异常值（outlier）特别敏感。数据里有一套凶宅卖了 1 元，MSE 会被这个样本彻底带偏。这时可以改用 MAE 或 Huber Loss。

2.4 分类问题：MSE 不好使了

上面讲的是回归（预测一个连续数字，如房价、温度）。

但很多任务是分类（预测一个类别，如"这是猫还是狗"、"下一个词是哪个"）。分类问题用 MSE 效果很差，需要另一把尺子。

分类模型输出的是"概率"

分类模型不会直接吐出"猫"，而是吐出每个类别的概率：

类别 模型输出概率
猫 0.7
狗 0.2
兔子 0.1

真实答案（标签）写成 one-hot 形式，即"正确的那个是 1，其余都是 0"：

类别 真实标签
猫 1
狗 0
兔子 0

交叉熵：只盯着"正确答案的那个概率"

交叉熵损失（Cross-Entropy Loss）：

Loss = − Σ yᵢ · log(ŷᵢ)

因为 one-hot 标签里只有正确类别是 1，其余是 0，所以这个求和实际上只剩正确类别那一项：

Loss = − log(正确类别的预测概率)

看几组数字就懂了：

模型给正确答案的概率 −log(p) 损失大小 含义
0.99 0.01 极小 答对了，很自信，几乎不罚
0.70 0.36 小 答对了，但不够自信
0.50 0.69 中 蒙的
0.10 2.30 大 基本答错
0.01 4.61 很大 错得离谱且很自信
→0 →∞ 无穷大 极刑

交叉熵的精髓：不只看"对不对"，还看"有多自信"。 自信地答错，惩罚极重；犹豫地答对，也有一定惩罚。这正是我们想要的训练信号。

import numpy as np

def cross_entropy(p_correct):
    return -np.log(p_correct)

for p in [0.99, 0.7, 0.5, 0.1, 0.01]:
    print(f"正确类概率={p:.2f}  损失={cross_entropy(p):.3f}")

2.5 Softmax：把任意数字变成概率

问题来了：神经网络最后一层输出的是任意实数（比如 [2.3, -1.1, 0.5]），怎么变成"加起来等于 1 的概率"？

答案是 Softmax：

softmax(zᵢ) = e^(zᵢ) / Σ e^(zⱼ)

三步走： 1. 每个数取指数 e^z（保证全部变成正数，且放大差距） 2. 全部加起来当分母 3. 每个除以总和（保证加起来 = 1）

import numpy as np

z = np.array([2.3, -1.1, 0.5])
exp_z = np.exp(z)              # [9.97, 0.33, 1.65]
probs = exp_z / exp_z.sum()    # [0.834, 0.028, 0.138]
print(probs, probs.sum())      # 加起来 = 1.0

🔑 这就是大模型"预测下一个词"的最后一步：模型对词表里 5 万个词各算一个分数，Softmax 转成概率，然后按概率采样一个词出来。你在 L2 课程里看到的"temperature 温度参数"，就是在 Softmax 之前给 z 除以一个数——除得越大，概率分布越平，输出越随机。

2.6 两把尺子怎么选

任务类型 例子 输出层 损失函数
回归 房价、温度、销量 直接输出实数 MSE
二分类 垃圾邮件 / 正常 Sigmoid（1 个输出） 二元交叉熵 BCE
多分类 猫/狗/兔，下一个词 Softmax（N 个输出） 交叉熵 CE

在 PyTorch 里就是一行：

import torch.nn as nn

loss_fn = nn.MSELoss()              # 回归
loss_fn = nn.BCELoss()              # 二分类
loss_fn = nn.CrossEntropyLoss()     # 多分类（内部已含 Softmax，别重复加）

2.7 关键认知：损失函数是模型的"人生目标"

这句话值得单独拎出来：

你定义什么损失函数，模型就会不择手段地把那个数字降到最低。

这既是威力也是陷阱：

  • 你让它最小化"预测点击率的误差" → 它可能学会推荐标题党
  • 你让它最小化"下一个词的交叉熵" → 它学会流畅地说话，但不保证说真话（这正是大模型"幻觉"的根源之一）
  • 你让它最小化"人类打分的负值" → 这就是 RLHF（L6 课程内容），也是 ChatGPT 比原始 GPT 好用的原因

模型没有价值观，只有损失函数。 记住这句话，你对 AI 的很多"奇怪行为"就都能理解了。

2.8 本章小结

  • 损失函数 = 给模型打分的尺子，数字越小说明模型越好
  • 误差不能直接相加（正负抵消），要平方或取绝对值
  • MSE 用于回归：重罚大错、处处可导
  • 交叉熵 用于分类：只看正确答案的概率，"自信地答错"惩罚最重
  • Softmax 负责把任意实数变成概率分布，是大模型输出词的最后一步
  • 损失函数决定了模型的行为目标，选错尺子等于教错方向
