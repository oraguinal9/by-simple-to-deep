第一章 从一条直线开始：模型、参数与预测

本章目标：不用任何术语吓唬人，先说清楚三个词——模型、参数、预测。这三个词是整个深度学习的地基，后面所有内容都是它们的加强版。

1.1 一个卖房子的小故事

假设你要卖房，想知道该定价多少。你手上有小区里最近成交的 5 套房：

面积（㎡） 成交价（万元）
60 186
75 232
90 281
105 325
120 377

你盯着这张表看了一会儿，心里冒出一个念头：价格差不多是面积乘以 3.1。

  • 60 × 3.1 = 186 ✅
  • 90 × 3.1 = 279（实际 281，差 2 万）
  • 120 × 3.1 = 372（实际 377，差 5 万）

不完全准，但八九不离十。恭喜你，你刚刚建立了一个模型。

1.2 什么是模型？

模型就是一个从「输入」算出「输出」的规则。

上面那个规则写成公式就是：

价格 = 3.1 × 面积
  • 输入：面积（我们叫它 特征 / feature，习惯用 x 表示）
  • 输出：价格（我们叫它 预测值 / prediction，习惯用 ŷ，读作 "y hat"）
  • 规则本身：就是模型

再抽象一点，写成教科书上的样子：

ŷ = w · x + b

这就是传说中的线性模型。别被名字唬住，它就是一条直线：

  • w（weight，权重）：直线的斜率——面积每涨 1 ㎡，价格涨多少
  • b（bias，偏置）：直线的截距——面积为 0 时的"基础价"，可以理解成装修、地段带来的固定加成

在我们的例子里，w = 3.1，b = 0。

1.3 什么是参数？

w 和 b 这两个可以调的数字，就叫参数（parameter）。

这里有一个非常关键的认知，请一定记住：

模型的"形状"（是直线还是曲线）由你选定；模型的"具体样子"由参数决定。而参数不是人手动调的，是从数据里"学"出来的。

你可以把参数想象成收音机上的旋钮：

  • 旋钮的种类和数量是设计好的（这就是"网络结构"）
  • 旋钮具体拧到哪个位置，要靠不断试听、调整（这就是"训练"）
概念 收音机类比 房价例子
模型结构 收音机有几个旋钮 一条直线：ŷ = wx + b
参数 旋钮拧到的位置 w=3.1, b=0
训练 边听边拧，直到声音清楚 边算误差边调 w、b
预测 拧好后正常收听 输入 150㎡，输出 465 万

深度学习的"深"，本质上就是旋钮特别多。 GPT-3 有 1750 亿个旋钮，原理和这两个旋钮完全一样。

1.4 参数不止一个：多特征

现实中房价当然不只看面积。假设还要看楼层和房龄：

价格 = w₁ × 面积 + w₂ × 楼层 + w₃ × 房龄 + b

现在有 4 个参数（w₁, w₂, w₃, b）。可以预期：

  • w₁ 是正数（面积越大越贵）
  • w₃ 大概率是负数（房龄越老越便宜）

这就叫多元线性回归。特征从 1 个变成 3 个，参数从 2 个变成 4 个，公式变长了，但思想一模一样。

当特征有几千几万个时，一个个写太麻烦，于是数学上用向量打包：

ŷ = w · x + b        （w 和 x 都是向量，中间是点积）

所谓"点积"，就是对应位置相乘再全部加起来，没有任何玄机：

# 手写点积，看清楚它在干什么
x = [90, 6, 5]          # 面积90㎡、6楼、房龄5年
w = [3.1, 2.0, -1.5]    # 三个权重
b = 10

y_hat = 0
for i in range(len(x)):
    y_hat += w[i] * x[i]
y_hat += b

print(y_hat)   # 3.1*90 + 2.0*6 + (-1.5)*5 + 10 = 292.5

1.5 为什么要写成"矩阵乘法"

如果你有 1000 套房要一起预测，一套套循环太慢。于是把 1000 套房堆成一个表格（矩阵 X，1000 行 × 3 列），一次算完：

Ŷ = X · W + b        （一次算出 1000 个预测值）

这就是显卡（GPU）能加速深度学习的根本原因：GPU 特别擅长同时做成千上万个乘加法。你后面看到的所有"矩阵乘法"，本质都是这一步——一堆乘法加起来。

import numpy as np

X = np.array([[60,3,10],[75,8,2],[90,6,5]])   # 3套房，每套3个特征
W = np.array([3.1, 2.0, -1.5])
b = 10

Y = X @ W + b        # @ 就是矩阵乘法
print(Y)             # [181.  240.5 292.5]  一次算出3个预测

1.6 预测 vs 训练：两个方向

初学者最容易糊涂的一点，是搞不清"模型在干嘛"。其实只有两个方向：

方向一：预测（推理 / inference）

已知 w、b  +  新的 x   →   算出 ŷ

这是你用 ChatGPT 时发生的事：参数早就训练好了，你给输入，它算输出。参数不变。

方向二：训练（training）

已知一堆 (x, 真实y) →  反过来找出最合适的 w、b

这是模型"学习"的过程。参数不断被修改。

训练 预测
需要真实答案吗 需要 不需要
参数会变吗 会，一直在变 不会，固定
耗时 很久（几天到几个月） 很快（毫秒到秒）
花钱 极贵 相对便宜
类比 学生做题订正 学生考试答题

本课程第 2、3、6 章讲的都是"训练"是怎么发生的，这也是深度学习最核心的秘密。

1.7 直线不够用怎么办？

聪明的你肯定发现问题了：现实世界哪有那么多直线关系？

比如"学习时间 vs 考试成绩"：一开始多学 1 小时提分很多，学到 90 分以后再学 10 小时也就多 1 分。这是一条弯曲的线，直线拟合不了。

解决办法有两条路：

  1. 换个更复杂的公式（比如加平方项）——但你怎么知道该加什么？现实问题太复杂，人猜不出来。
  2. 把很多简单的直线叠起来，中间加一点"弯曲"操作——让模型自己长出复杂形状。

第 2 条路就是神经网络。 这也是第四、五章要讲的内容：

直线 + 非线性激活 + 堆很多层 = 可以逼近几乎任何形状的函数

这句话被称为万能近似定理（Universal Approximation Theorem），是神经网络能work的理论依据。

1.8 本章小结

术语 一句话解释
模型 从输入算出输出的规则
参数（w, b） 规则里可以调整的数字，靠数据学出来
特征 x 喂给模型的输入信息
预测值 ŷ 模型算出来的答案
真实值 y 数据里的标准答案
线性模型 ŷ = wx + b，一条直线
训练 用 (x, y) 反推最合适的参数
推理 参数固定，用新 x 算 ŷ

一句话记住本章：深度学习不神秘，它就是"一堆带旋钮的乘加法"，难点在于怎么把上亿个旋钮自动拧到正确位置。
