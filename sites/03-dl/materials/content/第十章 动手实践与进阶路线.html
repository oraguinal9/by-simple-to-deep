10.2 完整项目：手写数字识别（MNIST）

这是深度学习的"Hello World"。下面这份代码用到了本课程 1~7 章的全部知识，可以直接复制运行，CPU 上大约 3~5 分钟跑完。

import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

# ========== ① 数据 ==========
tf = transforms.Compose([
    transforms.ToTensor(),                       # 转成张量，像素缩放到 0~1
    transforms.Normalize((0.1307,), (0.3081,)),  # 标准化（第七章）
])
train_set = datasets.MNIST('./data', train=True,  download=True, transform=tf)
test_set  = datasets.MNIST('./data', train=False, download=True, transform=tf)

train_loader = DataLoader(train_set, batch_size=64, shuffle=True)   # 小批量（第三章）
test_loader  = DataLoader(test_set,  batch_size=256)

# ========== ② 模型（第四、五、七章）==========
model = nn.Sequential(
    nn.Flatten(),                    # 28×28 图 → 784 维向量
    nn.Linear(784, 256), nn.ReLU(),  # 全连接 + 激活
    nn.Dropout(0.2),                 # 防过拟合
    nn.Linear(256, 64),  nn.ReLU(),
    nn.Linear(64, 10),               # 10 类，不加 Softmax（损失函数内置）
)

# ========== ③ 损失与优化器（第二、三章）==========
loss_fn   = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)

# ========== ④ 训练循环（第三、六章的五步）==========
def evaluate():
    model.eval()                                 # 关闭 Dropout！（第七章的坑）
    correct = 0
    with torch.no_grad():                        # 推理不需要计算图，省内存
        for x, y in test_loader:
            correct += (model(x).argmax(1) == y).sum().item()
    return correct / len(test_set)

for epoch in range(1, 4):
    model.train()                                # 开启 Dropout
    for i, (x, y) in enumerate(train_loader):
        pred = model(x)                          # ① 前向
        loss = loss_fn(pred, y)                  # ② 损失
        optimizer.zero_grad()                    # ③ 清梯度
        loss.backward()                          # ④ 反向
        optimizer.step()                         # ⑤ 更新
        if i % 300 == 0:
            print(f"epoch {epoch}  step {i:4d}  loss {loss.item():.4f}")
    print(f">>> 第 {epoch} 轮结束，测试集准确率：{evaluate()*100:.2f}%\n")

torch.save(model.state_dict(), "mnist_mlp.pt")
print("模型已保存到 mnist_mlp.pt")

预期结果：3 轮后测试准确率约 97%。

进阶挑战（做完你就真的懂了）

  1. 把 Dropout 去掉，观察训练/测试准确率的差距变化 → 亲眼看到过拟合
  2. 把学习率改成 1.0，看损失怎么炸掉 → 亲眼看到学习率的重要性
  3. 把中间两层删掉只留 Linear(784,10)，看准确率掉到多少 → 理解深度的价值
  4. 把网络换成第八章的 CNN（Conv2d），准确率能到 99%+ → 理解 CNN 对图像的优势
  5. 把 ReLU 换成 Sigmoid，看收敛速度变化 → 理解激活函数的影响

10.3 调试清单：模型不 work 怎么办

这份清单来自实战，按顺序排查能解决 90% 的问题。

症状：损失变成 NaN

  • [ ] 学习率太大 → 降 10 倍试试
  • [ ] 数据里有 NaN 或 inf → print(x.isnan().any()) 检查
  • [ ] 除以了 0 或对 0 取 log → 加 eps=1e-8
  • [ ] 梯度爆炸 → 加梯度裁剪 clip_grad_norm_(params, 1.0)

症状：损失完全不下降

  • [ ] 忘了 optimizer.zero_grad() 或 loss.backward()（头号 bug）
  • [ ] 学习率太小 → 提高 10 倍
  • [ ] 数据没归一化 → 像素值 0~255 直接喂进去很难训
  • [ ] 标签和数据对错位了 → 打印几条人工核对
  • [ ] 模型太简单，欠拟合 → 加大网络

症状：训练集好、测试集差

  • [ ] 典型过拟合 → 回看第七章六种武器
  • [ ] 数据泄漏：测试集信息混进了训练集
  • [ ] 忘了 model.eval() → Dropout/BatchNorm 在推理时行为不对

症状：训练极慢

  • [ ] 没用 GPU → model.to('cuda')，数据也要 .to('cuda')
  • [ ] batch size 太小 → 加大到显存允许的上限
  • [ ] DataLoader 是瓶颈 → 设 num_workers=4

万能第一步：先用 5 条数据训练，看模型能否过拟合到损失≈0

如果连 5 条数据都记不住，一定是代码有 bug，而不是模型不够强。这个技巧能帮你省下无数小时。

   ↓

   ↓
第10章 动手 + 进阶

如果只让你记住五句话：

  1. 模型是带参数的函数，参数靠数据学出来
  2. 损失函数定义了模型的"人生目标"
  3. 训练 = 沿负梯度方向反复微调参数
  4. 深度的价值在于层级特征抽象
  5. 目标永远是泛化，不是在训练集上刷分

10.8 结语

回头看，深度学习其实只有四件事：

① 定义一个带参数的函数 → ② 定义一把衡量错误的尺子 → ③ 用梯度下降调参数 → ④ 想办法让它在没见过的数据上也管用。

从 1 个参数的直线，到 1750 亿参数的 GPT，这四件事从未改变。你已经掌握了它们。
