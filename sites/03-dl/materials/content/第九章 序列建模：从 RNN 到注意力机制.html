第九章 序列建模：从 RNN 到注意力机制

本章目标：理解"有顺序的数据"为什么特殊，RNN 是怎么处理它的、卡在哪里，以及注意力机制如何一举解决所有问题——这一章正好是通往 L2《大模型原理》的桥。

9.1 序列数据的特殊性

前面讲的图像分类，每张图是独立的。但很多数据有先后顺序，且顺序改变意义就变：

数据类型 例子 顺序的重要性
文本 "我打他" vs "他打我" 词序决定语义
语音 音频波形 时间顺序即语言
股价 每日收盘价 趋势藏在时序里
视频 逐帧画面 帧序决定动作

固定结构的全连接和 CNN 处理这类数据有两个硬伤：

  1. 长度不固定。一句话可能 3 个字也可能 300 个字，全连接层的输入维度却是写死的。
  2. 无法建模长距离依赖。"我小时候在四川长大，所以我特别能吃……"——预测"辣"字，需要回看开头的"四川"。

9.2 RNN：带记忆的循环

循环神经网络（Recurrent Neural Network） 的想法很朴素：一个字一个字读，同时维护一个"记忆"。

        h₀ ──► [RNN] ──► h₁ ──► [RNN] ──► h₂ ──► [RNN] ──► h₃
                 ↑                ↑                ↑
                x₁("我")         x₂("爱")        x₃("你")

核心公式只有一行：

hₜ = tanh( W_h · h_{t−1} + W_x · xₜ + b )
  • hₜ：隐藏状态，可以理解为"读到目前为止的记忆摘要"
  • xₜ：当前时刻输入（比如当前这个字的向量）
  • W_h, W_x：所有时刻共享同一组权重（又是权重共享！）

类比：你读小说时，不会把前面所有文字都同时记在脑子里，而是维护一个"剧情摘要"，每读一句就更新一次摘要。hₜ 就是这个摘要。

import numpy as np

def rnn_step(x, h, Wx, Wh, b):
    return np.tanh(Wx @ x + Wh @ h + b)

hidden = 8
Wx, Wh, b = np.random.randn(hidden,4)*0.1, np.random.randn(hidden,hidden)*0.1, np.zeros(hidden)

h = np.zeros(hidden)                     # 初始记忆为空
sentence = [np.random.rand(4) for _ in range(5)]   # 假装是 5 个词的向量
for t, x in enumerate(sentence):
    h = rnn_step(x, h, Wx, Wh, b)
    print(f"读完第{t+1}个词，记忆向量前3维：{h[:3].round(3)}")

9.3 RNN 的三个致命伤

伤一：长距离依赖会忘

记忆 h 每步都被覆盖更新一次。传 20 步之后，第 1 步的信息基本被稀释没了。

数学上就是第六章讲的梯度消失：反向传播要穿过 20 个 tanh，梯度连乘后趋近于 0。

"我在法国长大……（中间 50 个字）……所以我说一口流利的 ____" 人类知道填"法语"，普通 RNN 早忘了"法国"。

伤二：无法并行

h₂ 必须等 h₁ 算完才能算。训练时只能一步一步串行，无法利用 GPU 的并行能力。

序列长度 1000 就要串行 1000 步——这直接卡死了模型规模的天花板。

伤三：信息瓶颈

在翻译任务里，整个源句子被压缩成一个固定长度的向量 h_final，再由它生成译文。

句子越长，这个向量越"挤"。就像让你读完一本书后只准写一句话摘要，然后别人根据这句话复述全书。

9.4 LSTM 与 GRU：给记忆装闸门

LSTM（长短期记忆网络） 的解法：不再粗暴覆盖记忆，而是用三个门（gate）来精细控制。

门 作用 类比
遗忘门 决定旧记忆里哪些该丢掉 擦掉笔记本上过时的内容
输入门 决定新信息里哪些值得记 只抄重点
输出门 决定当前该输出记忆的哪部分 按需回忆

每个门就是一个 Sigmoid 层，输出 0~1 的"开合程度"，再和记忆逐元素相乘。

关键改进：LSTM 维护一条细胞状态（cell state） C，它的更新是加法而非乘法：

Cₜ = 遗忘门 ⊙ C_{t−1} + 输入门 ⊙ 新候选

加法意味着梯度可以近乎无损地流过很多步——这和 ResNet 的残差连接是同一个思想。

GRU 是 LSTM 的简化版，把三个门减成两个，参数更少、速度更快，效果通常相当。

LSTM 缓解了"遗忘"（伤一），但无法并行（伤二）和信息瓶颈（伤三）依然存在。真正的突破还在后面。

9.5 注意力机制：直接去看原文

2014 年出现的注意力（Attention）机制，思路简单到令人拍案：

为什么非要把整句话压缩成一个向量？生成每个词的时候，直接回头去看原句中最相关的部分不就行了。

类比：你翻译一篇文章时，写到某个词，眼睛会自动瞟回原文对应的位置。你不需要背下全文。

三个角色：Query、Key、Value

注意力用一个"查字典"的框架来描述：

名字 含义 图书馆类比
Query（查询） 我现在想找什么 你的检索词
Key（键） 每个信息的索引标签 每本书的书名
Value（值） 每个信息的实际内容 书的正文

计算三步走：

  1. 算相关性：拿 Query 和每个 Key 做点积 → 得到一组分数（越大越相关）
  2. 归一化：Softmax 把分数变成加起来为 1 的权重（第二章的老朋友）
  3. 加权求和：按权重把所有 Value 混合起来 → 输出

写成公式就是那条著名的式子：

Attention(Q, K, V) = softmax( QKᵀ / √d ) · V
  • QKᵀ：算所有 Query 和所有 Key 的相关性
  • /√d：除以维度的平方根，防止点积过大导致 Softmax 饱和（梯度消失）
  • softmax：变成权重
  • · V：加权求和
import numpy as np

def attention(Q, K, V):
    d = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d)          # ① 相关性
    weights = np.exp(scores - scores.max(axis=-1, keepdims=True))
    weights /= weights.sum(axis=-1, keepdims=True)   # ② softmax
    return weights @ V, weights            # ③ 加权求和

Q = np.random.rand(3, 8)      # 3 个查询
K = np.random.rand(5, 8)      # 5 个候选信息
V = np.random.rand(5, 8)
out, w = attention(Q, K, V)
print("注意力权重矩阵（每行加起来=1）：\n", w.round(2))

自注意力（Self-Attention）

如果 Q、K、V 全都来自同一个句子，就叫自注意力——句子里的每个词，都去看句子里的所有词（包括自己），决定该关注谁。

例："它很好吃" 中的"它"，自注意力会让它和前文的"苹果"高度关联，从而正确理解指代。

这一步彻底解决了 RNN 的三个伤：

RNN 的问题 自注意力的解法
长距离遗忘 任意两个词直接连接，距离恒为 1 步
无法并行 所有位置同时计算，一个大矩阵乘法搞定
信息瓶颈 不压缩成单一向量，每个位置都保留完整表示

9.6 通向 Transformer

2017 年论文《Attention Is All You Need》做了一件狠事：把 RNN 彻底删掉，只留注意力。

Transformer 的组成部分，你现在应该全都认识了：

组件 出自本课程
多头自注意力 本章（多头 = 并行做几组注意力，各看不同角度）
位置编码 新增（因为注意力本身没有顺序概念，得额外告诉它谁先谁后）
前馈网络 FFN 第五章（就是两层全连接 + 激活）
激活函数 GELU 第四章
残差连接 Add 第五、六章
层归一化 Norm 第七章
Softmax 输出 第二章 
输入 → 词嵌入 + 位置编码
      ↓
   ┌─ 多头自注意力 ─┐
   │  → Add & Norm  │   ← 残差 + 层归一化
   │  → 前馈网络FFN │   ← 全连接 + GELU
   │  → Add & Norm  │
   └────────────────┘  ×  N 层（GPT-3 是 96 层）
      ↓
   线性层 → Softmax → 下一个词的概率分布

恭喜——你已经具备读懂 Transformer 的全部基础了。

9.7 注意力的代价

天下没有免费的午餐。自注意力要算每两个词之间的相关性，所以：

计算量 ∝ 序列长度²

序列翻倍，计算量变 4 倍。这就是为什么：

  • 早期 GPT 的上下文只有 2048 个 token
  • 长上下文（128K、1M）是各家大模型竞争的硬指标
  • 出现了大量优化技术：FlashAttention（优化显存读写）、稀疏注意力、滑动窗口注意力、线性注意力、以及回归 RNN 思路的 Mamba / RWKV

9.8 本章小结

  • 序列数据的特点：长度可变 + 顺序有意义 + 存在长距离依赖
  • RNN 靠隐藏状态 h 维护记忆，逐步更新，权重共享
  • RNN 三大伤：长距离遗忘、无法并行、信息瓶颈
  • LSTM/GRU 用门控 + 加法更新缓解了遗忘，但并行问题仍在
  • 注意力的本质：Query 找 Key，Softmax 得权重，加权求和 Value
  • 自注意力让任意两个位置直接相连，一举解决 RNN 三大伤
  • Transformer = 自注意力 + 位置编码 + FFN + 残差 + LayerNorm，全是本课程学过的零件
  • 代价是计算量与序列长度平方相关
