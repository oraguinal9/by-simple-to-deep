第六章 反向传播：链式法则的直觉理解

本章目标：讲清楚反向传播（Backpropagation）。这是深度学习里最"数学"的一章，但只要抓住"责任追溯"这个直觉，其实非常好懂。看完你就理解了 loss.backward() 这行代码背后发生了什么。

6.1 问题是什么

第三章我们知道，参数更新靠这条公式：

w ← w − η · (∂L/∂w)

对单个参数，我们手算过导数。但现在网络有几百万个参数，每一个都需要知道自己的 ∂L/∂w——损失对它的偏导数，也就是"我动一点点，损失会变多少"。

难点在于：一个第 1 层的权重，要经过第 2 层、第 3 层……才影响到最终损失。它的责任怎么算？

反向传播就是解决这个问题的算法。

6.2 直觉：一场责任追溯会议

设想一家公司业绩不佳（损失很大），老板要追责：

  1. 老板 → 部门总监："这季度亏了 100 万，各部门各占多少责任？"
  2. 总监 → 组长：销售总监分到 60 万责任，他再往下分给手下三个组
  3. 组长 → 员工：某组长分到 20 万，继续拆给组员

追责是从上往下、逐层拆分的，而且每一层的拆分比例，取决于"这个下属对上级结果的影响有多大"。

反向传播一模一样：从最终损失出发，逐层往回算"每个参数应负多少责任"。这个责任的数学名字就是梯度。

公司类比 神经网络
总亏损 100 万 损失 L
某部门的责任 该层输出的梯度 ∂L/∂h
某员工的责任 该参数的梯度 ∂L/∂w
"他影响多大" 局部导数
从上往下追责 从输出层往输入层反向传播

6.3 数学工具：链式法则

链式法则（Chain Rule）说的是：

如果 z 依赖 y，y 依赖 x，那么   dz/dx = (dz/dy) × (dy/dx)

用齿轮理解：

  • 大齿轮 x 转 1 圈 → 中齿轮 y 转 3 圈（dy/dx = 3）
  • 中齿轮 y 转 1 圈 → 小齿轮 z 转 2 圈（dz/dy = 2）
  • 所以 x 转 1 圈 → z 转 3 × 2 = 6 圈

影响是"相乘"传递的，这就是链式法则的全部。

多层网络就是多个齿轮串联：

w₁ → z₁ → h₁ → z₂ → h₂ → z₃ → ŷ → L

那么：

∂L/∂w₁ = (∂L/∂ŷ)·(∂ŷ/∂z₃)·(∂z₃/∂h₂)·(∂h₂/∂z₂)·(∂z₂/∂h₁)·(∂h₁/∂z₁)·(∂z₁/∂w₁)

看着吓人，但它只是一串乘法。而且每一项都很简单（下面就看到）。

6.4 手算一个两层网络

我们用最小的例子，把每个数字都算出来。

网络（为了简单，不加偏置，激活用 ReLU）：

x → [w₁] → z₁ → ReLU → h → [w₂] → ŷ → 损失 L=(ŷ−y)²

给定：x = 2，w₁ = 0.5，w₂ = 3，真实值 y = 4

第一步：前向传播（算出预测和损失）

z₁ = w₁ · x   = 0.5 × 2 = 1
h  = ReLU(1)  = 1                 （正数原样通过）
ŷ  = w₂ · h   = 3 × 1 = 3
L  = (ŷ − y)² = (3 − 4)² = 1

第二步：反向传播（从后往前算梯度）

① 损失对预测的导数

L = (ŷ − y)²
∂L/∂ŷ = 2(ŷ − y) = 2(3 − 4) = −2

含义：ŷ 每增大 1，L 减少 2。所以 ŷ 应该增大。

② 对 w₂ 的梯度

ŷ = w₂ · h        →  ∂ŷ/∂w₂ = h = 1
∂L/∂w₂ = (∂L/∂ŷ) × (∂ŷ/∂w₂) = −2 × 1 = −2

梯度是负的 → 更新时 w₂ ← w₂ − η·(−2) → w₂ 会变大。合理，因为预测 3 小于真实 4。

③ 梯度继续往回传给 h

∂ŷ/∂h = w₂ = 3
∂L/∂h = (∂L/∂ŷ) × (∂ŷ/∂h) = −2 × 3 = −6

④ 穿过 ReLU

ReLU 的导数极其简单：

z > 0  →  导数 = 1（原样通过）
z ≤ 0  →  导数 = 0（梯度被掐断）

这里 z₁ = 1 > 0，所以：

∂L/∂z₁ = −6 × 1 = −6

⑤ 对 w₁ 的梯度

z₁ = w₁ · x       →  ∂z₁/∂w₁ = x = 2
∂L/∂w₁ = −6 × 2 = −12

第三步：更新参数（学习率 0.01）

w₂ ← 3   − 0.01×(−2)  = 3.02
w₁ ← 0.5 − 0.01×(−12) = 0.62

验算：用新参数再前向一次

z₁ = 0.62 × 2 = 1.24
h  = 1.24
ŷ  = 3.02 × 1.24 = 3.74
L  = (3.74 − 4)² = 0.0676     ← 从 1 降到 0.068 ✅

损失确实下降了。这就是一次完整的学习。

6.5 代码验证

用 PyTorch 跑一遍，看梯度是不是我们手算的那些数：

import torch

x = torch.tensor(2.0)
y = torch.tensor(4.0)
w1 = torch.tensor(0.5, requires_grad=True)   # 标记：需要算梯度
w2 = torch.tensor(3.0, requires_grad=True)

# 前向
z1 = w1 * x
h  = torch.relu(z1)
y_hat = w2 * h
loss = (y_hat - y) ** 2

# 反向：一行搞定
loss.backward()

print("loss   =", loss.item())      # 1.0
print("dL/dw1 =", w1.grad.item())   # -12.0  ✅ 和手算一致
print("dL/dw2 =", w2.grad.item())   #  -2.0  ✅ 和手算一致

loss.backward() 这一行，做的就是我们上面手算的 5 步。 只不过 PyTorch 会对几百万个参数同时做，且全自动。

6.6 为什么叫"反向"，以及为什么它高效

关键在于复用中间结果。

注意 ④ 和 ⑤ 两步：算 ∂L/∂w₁ 时，我们直接用了上一步算出的 ∂L/∂h = −6，不需要从头再乘一遍。

如果每个参数都从头算，复杂度是 O(参数量 × 层数)。反向传播从后往前算一遍，顺手把所有参数的梯度都得到了，复杂度只有 O(参数量)——和前向传播差不多。

这正是深度学习能训练超大模型的工程基础。经验法则：一次反向传播的耗时大约是一次前向的 2 倍。

6.7 梯度消失与梯度爆炸

链式法则是连乘，这带来两个著名问题：

梯度消失（Vanishing Gradient）

如果每层的导数都小于 1（比如 Sigmoid 最大导数只有 0.25）：

0.25^10 ≈ 0.00000095    ← 传了 10 层，梯度几乎没了

后果：浅层参数几乎不更新，网络"前半截"学不动。

梯度爆炸（Exploding Gradient）

如果每层导数都大于 1：

1.5^20 ≈ 3325           ← 梯度暴涨

后果：参数一步跳到天上，损失变成 NaN，训练崩溃。

现代解决方案：

问题 解法 说明
梯度消失 ReLU 系激活 正区间导数恒为 1，不衰减
梯度消失 残差连接 out = F(x)+x 梯度有一条"直达高速路"
两者 BatchNorm / LayerNorm 归一化，让每层输入分布稳定
梯度爆炸 梯度裁剪 clip 超过阈值就按比例缩回来
两者 合理的权重初始化 He / Xavier 
# 梯度裁剪：训练大模型/RNN 时几乎必加
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

6.8 计算图与自动微分

PyTorch 之所以能自动求导，是因为它在前向传播时偷偷记录了一张计算图：

w1 ──×── z1 ──ReLU── h ──×── ŷ ──(−y)²── L
      ↑                    ↑
      x                    w2
  • 每做一次运算，就在图上加一个节点，并记住"这个运算的导数怎么算"
  • 调用 .backward() 时，沿着图从 L 往回走，逐节点套链式法则

这套机制叫 自动微分（Autograd）。它意味着：你只需要写前向传播，反向传播框架自动帮你搞定。 这是深度学习框架最大的价值之一。

三个实用要点：

optimizer.zero_grad()   # ① 梯度是累加的，不清零会把上一轮的加进来（新手头号 bug）

with torch.no_grad():   # ② 推理时关掉计算图，省显存、提速
    preds = model(x)

loss.backward()         # ③ 默认反向后就释放计算图，同一张图不能 backward 两次

6.9 本章小结

  • 反向传播 = 从损失出发，逐层往回追溯每个参数的责任（梯度）
  • 数学工具是链式法则：影响沿着路径相乘传递
  • 手算流程：前向算出损失 → 从输出层往回逐层求偏导 → 得到每个参数的梯度 → 更新
  • ReLU 的导数只有 0 和 1，正区间原样传、负区间掐断
  • 反向传播高效的关键是复用中间梯度，一次回传拿到所有梯度
  • 连乘导致梯度消失/爆炸，靠 ReLU、残差连接、归一化、梯度裁剪解决
  • loss.backward() 背后是计算图 + 自动微分，你只需写前向
