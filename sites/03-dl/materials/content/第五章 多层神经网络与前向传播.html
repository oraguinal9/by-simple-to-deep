第五章 多层神经网络与前向传播

本章目标：把单个神经元组装成网络，理解层的概念、数据在网络里的流动过程（前向传播），以及"深度"到底带来了什么。

5.1 从神经元到层

一个神经元只能输出一个数字。把 N 个神经元并排，同时接收相同的输入，就得到一层（Layer）：

                ┌──► 神经元1 ──► a₁
   x₁ ─┐        │
   x₂ ─┼────────┼──► 神经元2 ──► a₂
   x₃ ─┘        │
                └──► 神经元3 ──► a₃
   输入 3 维              这一层输出 3 维

每个神经元有自己的一组权重。把 3 个神经元的权重堆成矩阵 W（3 行 × 3 列），整层的计算就浓缩成一行：

a = f(W · x + b)
  • x：输入向量（维度 = 输入特征数）
  • W：权重矩阵（行数 = 本层神经元数，列数 = 输入维度）
  • b：偏置向量（维度 = 本层神经元数）
  • f：激活函数，逐元素作用

这种"每个输入都连到每个神经元"的层，叫全连接层（Fully Connected / Dense / Linear Layer）。

参数量怎么算：输入 n 维、输出 m 维的全连接层，参数量 = n×m + m。

举例：784 → 128 的层（MNIST 手写数字识别第一层），参数量 = 784×128 + 128 = 100,480 个。

5.2 堆成网络

把多层串起来，上一层的输出作为下一层的输入：

输入层        隐藏层1        隐藏层2        输出层
 x (784)  →   h₁ (128)  →   h₂ (64)   →   y (10)
            ReLU          ReLU        Softmax

三类层的角色：

层 作用 备注
输入层 接收原始数据 不做计算，只是数据入口，通常不算作"一层"
隐藏层 提取、变换特征 层数和宽度是你设计的，网络的能力来源
输出层 给出最终答案 维度由任务决定：回归 1 维、10 分类 10 维

"深度学习"的深，指的就是隐藏层多。上面这个网络有 2 个隐藏层，算是很浅的了；ResNet-152 有 152 层；GPT-3 有 96 层 Transformer Block。

5.3 前向传播：一次完整的计算

前向传播（Forward Propagation） = 数据从输入层一路算到输出层的过程。

以上面的网络为例：

z₁ = W₁·x  + b₁       h₁ = ReLU(z₁)      # 784 → 128
z₂ = W₂·h₁ + b₂       h₂ = ReLU(z₂)      # 128 → 64
z₃ = W₃·h₂ + b₃       ŷ  = Softmax(z₃)   # 64  → 10

就这么三组、六个公式。任何前馈神经网络的前向传播，都是这样一层套一层。

用 numpy 完整实现一遍：

import numpy as np

def relu(z):
    return np.maximum(0, z)

def softmax(z):
    e = np.exp(z - np.max(z))     # 减最大值防止指数溢出（工程小技巧）
    return e / e.sum()

# 随机初始化三层参数
np.random.seed(0)
W1, b1 = np.random.randn(128, 784) * 0.01, np.zeros(128)
W2, b2 = np.random.randn(64, 128)  * 0.01, np.zeros(64)
W3, b3 = np.random.randn(10, 64)   * 0.01, np.zeros(10)

def forward(x):
    h1 = relu(W1 @ x + b1)
    h2 = relu(W2 @ h1 + b2)
    y  = softmax(W3 @ h2 + b3)
    return y

x = np.random.rand(784)           # 假装是一张 28×28 的手写数字图
probs = forward(x)
print(probs.round(3), probs.sum())
print("预测数字：", probs.argmax())

对应的 PyTorch 写法（实际工作中用这个）：

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 128), nn.ReLU(),
    nn.Linear(128, 64),  nn.ReLU(),
    nn.Linear(64, 10),                 # CrossEntropyLoss 内含 Softmax，这里不用加
)

5.4 网络到底在学什么？——层级特征

这是深度学习最迷人的地方。以图像识别为例，把各层学到的东西可视化，会发现明显的层级结构：

层次 学到的东西 类比
第 1~2 层 边缘、颜色块、明暗渐变 笔画
中间层 纹理、角、圆弧、简单形状 偏旁部首
较深层 眼睛、轮子、车灯、耳朵 汉字
最深层 猫脸、汽车、人脸 词语、句意

每一层都在前一层的基础上，把简单特征组合成更复杂的特征。 这就是"深度"的价值——不是简单地增加参数，而是构建抽象的层次。

在语言模型里也是同样的规律：浅层学词性和局部语法，中层学句法结构和指代关系，深层学语义和逻辑关系。

5.5 该设计多深、多宽？

这是个工程问题，有一些经验规律：

宽度（每层神经元数）

  • 常见取 2 的幂：64、128、256、512、1024
  • 通常逐层递减（784 → 256 → 64 → 10），像漏斗一样逐步压缩信息
  • 太窄会成为信息瓶颈，太宽浪费算力且容易过拟合

深度（层数）

  • 简单表格数据：2~3 层足够，再深往往没有收益
  • 图像：几十层起步（用 CNN，见第八章）
  • 语言：Transformer 12~96 层不等

深 vs 宽：同样的参数预算，一般"深"比"宽"更划算，因为深度带来的是特征的层次组合，表达能力呈指数增长；单纯加宽只是线性增加容量。

⚠️ 但不是越深越好。层数太多会遇到梯度消失、退化等问题。2015 年的 ResNet 用"残差连接"（输出 = F(x) + x，给梯度开一条高速公路）解决了这个问题，才让上百层的网络成为可能。今天所有 Transformer 里也都有残差连接，你在 L2 课程里见过的 Add & Norm 就是它。

5.6 批量处理：一次算一堆

实际训练时不会一条一条算，而是一批（batch）一起算。只需把输入从向量变成矩阵：

单条：  x 是 (784,)          →  ŷ 是 (10,)
一批：  X 是 (32, 784)       →  Ŷ 是 (32, 10)     # 32 = batch size

公式几乎不变，只是矩阵形状变了：

H₁ = ReLU(X @ W₁ᵀ + b₁)      # (32,784) @ (784,128) = (32,128)

关键收益：GPU 可以并行算完这 32 条，耗时和算 1 条差不多。这就是为什么 batch size 越大训练越快（直到显存装不下）。

import numpy as np
X = np.random.rand(32, 784)                 # 一批 32 张图
H1 = np.maximum(0, X @ W1.T + b1)           # (32, 128)
print(H1.shape)

5.7 一个完整的可运行例子

用 PyTorch 训练一个网络拟合 y = sin(x)，把前五章的知识全用上：

import torch, torch.nn as nn

# 1) 造数据
x = torch.linspace(-6, 6, 500).unsqueeze(1)      # (500,1)
y = torch.sin(x)

# 2) 定义模型：2 个隐藏层，各 64 个神经元（第4、5章）
model = nn.Sequential(
    nn.Linear(1, 64), nn.Tanh(),
    nn.Linear(64, 64), nn.Tanh(),
    nn.Linear(64, 1),
)

# 3) 损失函数与优化器（第2、3章）
loss_fn = nn.MSELoss()
opt = torch.optim.Adam(model.parameters(), lr=0.01)

# 4) 训练循环（第3章的五步）
for epoch in range(2000):
    pred = model(x)                # ① 前向
    loss = loss_fn(pred, y)        # ② 损失
    opt.zero_grad()                # ③ 清梯度
    loss.backward()                # ④ 反向
    opt.step()                     # ⑤ 更新
    if epoch % 400 == 0:
        print(f"epoch {epoch:4d}  loss {loss.item():.5f}")

print("训练完成，模型已经学会 sin 曲线的形状")

注意：模型完全不知道什么是"正弦函数"，它只是用一堆直线段 + tanh 弯曲，硬生生拼出了那条波浪线。这就是万能近似定理的实际体现。

5.8 本章小结

  • 层 = 一排并列的神经元，计算浓缩成 a = f(Wx + b)
  • 全连接层参数量 = 输入维 × 输出维 + 输出维
  • 前向传播 = 数据从输入层逐层算到输出层
  • 深度的意义是层级特征抽象：边缘 → 纹理 → 部件 → 物体
  • 宽度常用 2 的幂并逐层递减；深度按任务定；同等参数下深比宽划算
  • 太深会退化，残差连接（out = F(x) + x）是解药，Transformer 里也在用
  • 实际计算按 batch 批量进行，充分利用 GPU 并行
