第八章 DPO：不用强化学习也能对齐

前面七章都在讲 RLHF 的「标准姿势」：训奖励模型 + PPO 强化学习。这套流程有效，但又贵又复杂——要同时伺候 4 个模型、要调一堆超参、还容易被奖励黑客折磨。

2023 年，一篇叫 DPO（Direct Preference Optimization，直接偏好优化） 的论文扔下了一句狠话：别训奖励模型了，也别跑强化学习了，直接用一个分类损失就能对齐。

这一章讲 DPO 到底怎么做到的，以及它和 PPO 该怎么选。

一、DPO 的核心洞察

PPO 的麻烦，一半来自「要先训一个 RM，再用 RL 去优化它」。DPO 的关键发现是：在特定的数学设定下，RLHF 的最优策略，可以直接用偏好数据写出来，而不需要显式训 RM、也不需要 RL 循环。

换句话说，原本「RM → RL」两步，被 DPO 压缩成了一步：直接在偏好对上做监督式的分类训练。

二、DPO 的损失函数（直觉版）

DPO 的训练目标长这样（别怕，我们拆开看）：

L_DPO = − log σ( β · ( log π(y_w|x) − log π(y_l|x) ) − β · ( log π_ref(y_w|x) − log π_ref(y_l|x) ) )

一堆对数，但本质就一句话：

让策略模型对「胜方 y_w」的概率，相对「败方 y_l」的概率，比参考模型时更高；而且这个「抬高幅度」由 β 控制。

对照着读：

  • log π(y_w|x) − log π(y_l|x)：当前策略下，偏好胜方胜过败方的程度；
  • log π_ref(...) 那一项：参考模型下同样的程度（作为基线扣掉）；
  • β：对齐强度，越大越「死守偏好」，越小越「随意」；
  • σ(...)：把差值压成 0~1 的概率，再用负对数做成损失。

肉眼可见的好处：这整套就是一个普通的监督分类损失，用标准 SGD/Adam 就能训，不需要采样、不需要 RM、不需要 PPO 的 four-model 流水线，也不需要 on-policy 重采样。

三、DPO 到底「偷」了什么

你可能会问：奖励去哪了？其实 DPO 并没有真的丢掉奖励，而是把它「隐式」吸收了——它证明：在 Bradley–Terry + KL 约束的 RLHF 设定下，最优策略里的「奖励差值」可以等价替换成「策略概率比值」。于是训练时我们直接优化策略概率，绕开了显式奖励建模和 RL 循环。

可以理解为：DPO 把「奖励模型 + 强化学习」两阶段，在数学上折叠成了一个阶段。

四、DPO vs PPO：一张对比表

维度 PPO (标准 RLHF) DPO
是否训奖励模型 要 不要（隐式）
是否跑强化学习 要（on-policy 循环） 不要
同框模型数 4 个（Actor/Critic/Ref/RM） 2 个（策略 + 参考，参考冻结）
训练稳定性 需精调 β/ε/学习率，易崩 较稳，像普通 SFT
算力/显存 高 低很多
防奖励黑客 KL 约束 + 需盯 RM 同样有 KL 式约束，但无显式 RM 可钻
可控性/灵活性 可加多奖励、过程奖励 相对简单，复杂奖励难表达
适用场景 超大模型、需精细控制、有 RM 基建 快速对齐、资源有限、偏好数据充足

五、DPO 不是「永远更好」

别被「不用 RL」误导，DPO 有它的边界：

  • 偏好数据质量要求高：DPO 直接吃偏好对，数据噪声会被更直观地放大；
  • 偏好要覆盖目标分布：如果训练分布的 prompt 和线上差太远，DPO 也会偏；
  • 复杂奖励难表达：想同时优化「有用 + 安全 + 格式 + 长度」多个维度，PPO 的多奖励组合更灵活；
  • 极端/长尾安全：有 RM 时你能单独给安全维度加权、做红队；DPO 把这些揉进一对偏好里，较难精细操控。

所以业界常见做法是：小模型/快速迭代用 DPO，超大模型/强可控用 PPO，甚至两者结合（先用 DPO 粗调，再上 PPO 精修）。

六、一个延伸：RLAIF / Constitutional AI

既然人类标注贵，能不能让另一个强模型来生成偏好？这就是 RLAIF（AI Feedback） 和 Constitutional AI（宪法式 AI） 的思路：用一套「原则/宪法」让模型自我批评、自我对齐，大幅减少对人类标注的依赖。它们既可以用在 RM 训练，也可以直接用 DPO 式的损失消化 AI 生成的偏好。

本章小结

  • DPO 的洞见：RLHF 最优策略可直接用偏好数据写出，无需显式 RM、无需 RL 循环。
  • DPO 损失本质：让策略模型「胜方概率相对败方」比参考模型时更高，由 β 控制强度——就是一个监督分类损失。
  • DPO 把「RM + RL」两阶段折叠成一阶段，显存/算力骤降、训练更稳。
  • 对比 PPO：DPO 简单便宜但偏好数据质量要求高、复杂奖励难表达；实践中常按规模/可控性混合使用。
  • 延伸：RLAIF / Constitutional AI 用 AI 反馈替代人类标注，是 DPO 思想的进一步放大。
