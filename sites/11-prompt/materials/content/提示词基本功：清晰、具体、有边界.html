提示词基本功：清晰、具体、有边界

为什么有人问同样的问题，得到的答案差那么多

你先别急着学那些花哨的技巧。在学「角色设定」「思维链」这些高级招数之前，有一件事怎么强调都不过分：把话说清楚。就像学武功先学站桩，提示词的基本功只有六个字——清晰、具体、有边界。

很多初学者有一个误区：觉得提示词写得越「玄乎」越好，像发功一样输出咒语。事实恰恰相反。大模型最怕的三种提示词，恰好对应三种最常见的失败模式：

  • 太模糊：模型不知道你到底要什么，只能给一个「万金油」回答。
  • 太笼统：听起来要求不少，但没有一句是可执行的动作，模型无从下手。
  • 没边界：你没说「不要什么」，模型就顺手把不该有的东西也塞给你。

这一章，我们把「怎么把话说清楚」拆成可以照做的四步。先讲一个总的框架（四要素），再讲五个具体的写作技巧，然后讲「做什么 + 不做什么」的双向约束，最后给你一个从差到好的完整对照案例。

总框架：提示词四要素

还记得上一讲提到的「对话协议」吗？一份完整的协议，拆开来看就是四样东西，我们把它叫四要素：

要素 英文 一句话解释 举例
角色 Role 你希望模型以什么身份回答 你是一位有 10 年经验的产品经理
任务 Task 你希望它具体做什么 给下面这个需求写一份验收清单
背景 Context 做这件事需要的资料和前提 我们的产品是儿童电话手表，目标用户 6~12 岁
输出格式 Format 答案长什么样 用表格输出，每项包含编号、验收点、优先级

你可能已经发现，这四要素和上一讲的「三问」一脉相承，只是把「约束」拆成了「角色」和「输出格式」两块。四要素就是提示词工程的地基，后面每一章讲的技巧，都是在这块地基上加砖。

写提示词时，你可以把这四要素当成分检查单：角色说了吗？任务说清了吗？背景给足了吗？输出格式定了吗？ 四格都打上勾，这条提示词至少是「及格」的。

五个让提示词「变清楚」的写作技巧

四要素是骨架，以下五个技巧是血肉。它们每一个都对应一个常见的「不清楚」问题。

技巧一：用具体动词，别用模糊动词

「帮我看看」「帮我处理」「帮我弄一下」，这些词在大模型看来等于没说。「看看」是总结？是挑错？是翻译？是排版？「处理」更是可以指代一切。把它们换成能一步执行的具体动词。

模糊动词 换成
看看 总结 / 审校 / 找错 / 评价
处理 压缩 / 改写 / 翻译 / 排序
弄一下 起草 / 生成 / 计算 / 分类
优化 缩短到 200 字 / 把语气改成正式 / 突出三个卖点

一个好用的自检方法是：把提示词里的动词遮住，问自己「如果我是一个只会照做的人，我知不知道第一步该干什么」。 如果答案是「不知道」，那就继续改。

技巧二：限定范围，别让模型自由发挥

模型喜欢把答案往「大而全」方向写。你问「介绍一下杭州」，它能从地理写到历史再写到美食，写两千字。所以你要主动圈定范围：时间范围、空间范围、数量范围、视角范围。

  • 差：介绍一下杭州。
  • 好：请用 5 句话介绍杭州作为旅游城市最值得去玩的 3 个地方，不要谈历史，不要谈美食。

限定范围不只是为了省字数，更是为了降低幻觉风险——范围收得越窄，模型胡编的空间越小。

技巧三：给例子，比解释一百遍都有用

有些要求用文字很难说清，比如「轻松的语气」「有网感的表达」「高级感的配色描述」。这时候与其解释，不如直接给一个例子。模型看例子，比听抽象描述理解得快得多。这一招我们会在 few-shot 示例：用例子教会模型 一章里系统展开，这里先体会一下：

  • 只用描述：请用「小红书风格」的语气推荐这本书。
  • 描述 + 例子： text 请模仿下面的风格推荐这本书《置身事内》： 例子：「天呐这本宝藏书也太好读了吧！用大白话把中国的经济讲得明明白白，读完再看新闻瞬间懂了！」 注意：语气要像朋友安利，不要像书评家。

技巧四：说人话，别写「广告腔」和「学术腔」

初学者常犯的另一个错误，是把自己想象成在写「指令文档」，于是堆砌「请务必」「综上所述」「鉴于上述」这类废话。模型不需要这些客套。你越直白，它越准确。提示词就该像你给一个靠谱的实习生交代工作：一句话能说清的，绝不用两句。

技巧五：把「默认信息」也写进去

很多你觉得「不用说的前提」，模型恰恰不知道。比如你说「帮我改一下这份海报文案」，模型不知道：海报贴在哪里（地铁 / 朋友圈 / 电梯屏）？给谁看（年轻人 / 宝妈 / 老板）？改到什么程度（润色 / 重写）？这些对你来说是「想当然」，对模型来说是「盲区」。判断标准很简单：凡是你不写、模型就可能理解错的信息，都值得写进去。

双向约束：告诉它做什么，也告诉它不做什么

前面讲的都是「做什么」。但好提示词还有另一半：不做什么。就像跟人合作，光说「尽量做好」不够，还得说「有几条红线绝对不能碰」。

为什么要加「不要」条款？因为大模型的默认行为有很多「坏习惯」：喜欢编数据、喜欢啰嗦、喜欢把不确定的事说得确定、喜欢在结尾加一段万能升华。你写一条提示词，就等于给它一份「行为守则」，守则里既要有「该做的」，也要有「禁止的」。

一个经典例子。你让它总结一份会议纪要：

请总结下面这份会议纪要。

结果模型给你输出一段总结，末了还补了一句「总之，本次会议充分体现了团队的高效协作精神」。这种官腔总结，就是没有「不要」条款的代价。加上边界之后：

请总结下面这份会议纪要。
要求：
1. 只输出事实和结论，不要加任何评价性语言，比如「体现了」「充分展现了」这类话一律不写。
2. 不要虚构会上没有讨论的内容。
3. 控制在 200 字以内。
4. 用「决定 / 待办 / 风险」三个小标题分块。

加了四条「要 + 不要」之后，输出立刻干净很多。

关于「不要」条款，有两点提醒：

第一，「不要」要写具体行为，不要写抽象品质。 「不要啰嗦」不如「不要超过 200 字」；「要严谨」不如「不确定的别写，写『待核实』」。

第二，「不要」条款不是越多越好。 一次提示词里写七八条禁止项，模型会「顾此失彼」。挑你最在意的两三条就够了，其余用正向指令引导。

一个完整的「从差到好」对照案例

我们把上面的技巧全部放进一个真实场景，让你看一遍「差 → 中 → 好」三个版本的全过程。

场景：你是一家奶茶店的老板，想请 AI 帮忙写一条新品「桂花乌龙奶茶」的朋友圈推广文案。

差版本（模糊）

帮我写条朋友圈。

模型会给你一个放之四海而皆准的模板：「新品上市！好喝不贵！快来尝尝！」，毫无个性，也看不出和「桂花乌龙」有什么关系。失败原因：没角色、没背景、没格式。

中版本（有点想法，但没到位）

帮我写一条关于桂花乌龙奶茶的朋友圈文案，要吸引人一点，不要太长。

比第一版强，但「吸引人一点」「不要太长」都是模糊要求。模型只能靠猜：「吸引人」是卖萌？是种草？是制造稀缺？「不要太长」是 30 字还是 150 字？结果大概率是「普通但没惊喜」。

好版本（四要素齐备 + 双向约束）

你是一位擅长写朋友圈种草文案的营销高手。（角色）

我新推出一款「桂花乌龙奶茶」，卖点是：真桂花、乌龙茶底、微糖不腻、限量每天 50 杯。（背景）

请帮我写一条朋友圈文案，目标是让朋友看了就想去买一杯。（任务）

具体要求：
1. 150 字以内，用轻松、亲切的口吻，像朋友分享而不是广告。
2. 开头一句话抓眼球，中间点出两个卖点，结尾给一句行动号召（比如「今天不喝明天就没了」之类，但不要说谎，我们确实限量）。
3. 不要使用「爆款」「绝绝子」「yyds」这类用滥的词。
4. 不要写价格，价格我们后续在评论区定。
（输出格式与边界）

看，这一版把四要素和五个技巧全用上了：角色给了（营销高手）、任务给了（写文案）、背景给了（产品卖点）、输出格式给了（150 字 + 结构 + 禁忌词 + 不写价格）。模型拿到这份协议，写出来的东西就是「贴着你的店长」的定制文案，而不是通用模板。

一个细节：为什么「不要写价格」这一条特别值钱

注意好版本里的第 4 条：「不要写价格，价格我们后续在评论区定」。这一条很多新手会忽略——你可能觉得「反正卖点写清楚了，价格它不至于乱写吧？」但模型就是会乱写。你一旦没提价格，它为了「文案完整」，很可能顺手给你编一个「只要 19.9」之类的数字，而你真上架时价格可能是 25 元，朋友圈文案就成了虚假宣传。凡是「模型可能顺手编、而你必须严格控制」的信息，比如价格、日期、数量、具体数字，都要单独列成一条「不要写 / 必须写」条款。 这比笼统地说「要准确」管用得多——准确是个形容词，而「价格必须写 25 元 / 价格不要出现」是可执行的指令。

一张自查表：发出去之前，对照这 6 条

在你每次点击发送按钮之前，花 30 秒对照这张自查表。命中越多，输出越好：

  • [ ] 我有没有给模型一个明确的角色？
  • [ ] 我的动词是不是具体的动作？（总结 / 改写 / 列出，而不是「处理」）
  • [ ] 我有没有把「它不知道、但我心里知道」的背景写进去？
  • [ ] 我有没有圈定范围？（长度、数量、视角、时间）
  • [ ] 我有没有说清输出格式？
  • [ ] 我有没有写下两三条「不要」红线？

本章小结

  • 提示词的基本功就六个字：清晰、具体、有边界。
  • 四要素是总框架：角色、任务、背景、输出格式，写提示词时逐个打勾。
  • 五个技巧让提示词变清楚：用具体动词、限定范围、给例子、说人话、写足「默认信息」。
  • 好提示词是双向约束：「做什么」+「不做什么」，「不要」条款要写具体行为、控制条数。
  • 发送前用 6 条自查表过一遍，比追求任何「咒语」都管用。

基本功练好了，我们下一章就给提示词加一层「身份」：让模型扮演专家。很多时候，一个合适的角色设定，能让输出立刻上一个台阶。请阅读 角色设定：让模型扮演专家。
