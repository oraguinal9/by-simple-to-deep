ComfyUI 入门：节点式工作流

前两篇，我们认识了多模态，也理解了 SD 这个「画图引擎」。但从今天起，我们真正要打交道的主角登场了：ComfyUI——一个让无数新手又爱又怕、实际上却简单得离谱的工具。

一句话定义 ComfyUI：它是一个「可视化编程式」的 AI 画图工具，把「画一张图」的整个过程，拆成一堆可以拖来拖去的小方块（节点），用线连起来，就是一条流水线。

这篇我们分四步走：先搞懂它到底是什么、和另一个著名的画图工具 WebUI 有什么区别；然后把它装到电脑上；再认识它的界面；最后亲手把官方自带的一个示例工作流跑起来。别怕，每一步我都会给到可以直接照抄的命令和操作。

一、ComfyUI 是什么：把「画图」变成「搭积木」

先看一个容易让人蒙圈的对比：传统的画图工具（比如 Stable Diffusion WebUI）是一个「填表工具」——你在网页表单里填提示词、填参数，点一下「生成」，图就出来了。简单直观，但流程是写死的，你想加一步「先放大再上色」？做不到，只能装插件。

ComfyUI 完全反过来：它不给你一个现成的表单，而是给你一堆零件，让你自己拼流水线。 这听起来门槛更高，但好处是：

  • 想怎么改就怎么改：加一个节点 = 加一步处理，减一个节点 = 砍掉一步；
  • 看得见中间过程：每一步处理的中间结果都能预览，出问题一眼定位；
  • 可以复用和分享：一条拼好的流水线可以保存成文件，发给别人，别人加载就能用；
  • 效率高：内存管理更精细，同样一张图往往比 WebUI 更快、更省显存。

正因为灵活，ComfyUI 如今是本地 AI 创作圈的事实标准。它来自一个叫 Comfy 的开源项目，在 GitHub（全球最大的代码托管网站）上有超过十万颗星标——这个数字代表着全球无数人的信任和贡献。

心智模型（一定要记住）：把 ComfyUI 想象成乐高。 每个节点是一块乐高积木（比如「读取模型」「写提示词」「画图」「保存图片」），每根连线是积木之间的插槽。你拼出的整条积木车，叫工作流（workflow）。画一张图，本质上就是拼出并运行一条工作流。

1.1 节点长什么样

一个节点就是一个矩形小卡片，大致有这几个部分：

  • 顶部：节点名字（比如 Load Checkpoint「加载模型」、KSampler「采样器」）；
  • 左侧：输入端（input），画图所需的数据从这里进来，用「线」连进来；
  • 右侧：输出端（output），处理完的结果从这里出去，用「线」连出去；
  • 中间：一些可调的参数（比如分辨率、采样步数）。

每个节点的输入输出都必须匹配——就像乐高积木的凸点和凹槽，型号不对插不上。ComfyUI 会用颜色和形状告诉你什么能连什么：

连线颜色 传输的数据 举例
粉红 模型 checkpoint、LoRA
紫色 提示词（文本） 正向提示词、负向提示词
青色（蓝绿） 条件（编码后的语义） CLIP 编码结果
灰色 图片（潜空间/像素） 生成的图、VAE 输出
蓝色 参数（数字/滑杆） 步数、种子、CFG

颜色暂时不用背，跑起来自然就认识了。

二、ComfyUI vs WebUI：选谁？

你可能会在教程里看到另一种主流工具「Stable Diffusion WebUI」（一般叫 A1111，因为源自 Automatic1111 项目）。两者都是给 SD 用的界面，我们对比一下，帮你理解「为什么本阶选 ComfyUI」：

对比项 WebUI（A1111） ComfyUI
上手难度 低，填表单就行 中等，要理解节点
灵活性 低，流程写死 极高，任意拼装
中间过程可见性 弱 强，每步可预览
资源占用/速度 相对高 更省显存、更快
批量/自动化 一般 极强（API、参数化，第 9 篇讲）
社区现状 老牌，插件多 新主流，更新最快
适合谁 只想要简单出图 想进阶、想要自由、想自动化

结论：如果你只想「点几下出张图」，WebUI 更快；但本阶的目标是让你从「会出图」变成「能自由控制出图、能批量、能自动化」，这是 ComfyUI 的主场。 而且两者共用一套模型，学了 ComfyUI 之后你的模型文件两边都能用。

三、安装 ComfyUI：Windows 一键包

接下来进入实操。这一节以 Windows 系统为例，因为绝大多数读者用 Windows。安装方式有两种，推荐新手用第一种。

方式一：下载一键整合包（推荐新手）

国内社区（如秋叶、B 站 up 主）提供了「一键整合包」，把 ComfyUI 本体、Python 环境、常用插件、示例模型打包好了，解压就能用。步骤：

  1. 搜索「ComfyUI 整合包」或「ComfyUI 秋叶包」，在靠谱的下载页下载；
  2. 解压到一个路径里不要有中文和空格的目录（这一点非常重要！第 10 篇会专门讲为什么），比如：
E:\ComfyUI

而不是：

E:\我的工具\ComfyUI 新版（这样容易出问题）
  1. 双击目录里的启动脚本，一般叫 run_nvidia_gpu.bat（英伟达显卡）或 启动 ComfyUI.bat；
  2. 等待窗口里出现类似下面这行，说明服务启动成功：
To see the GUI go to: http://127.0.0.1:8188
  1. 打开浏览器，访问 http://127.0.0.1:8188，ComfyUI 界面就出现了。

127.0.0.1:8188 是什么意思？127.0.0.1 是「本机」的地址（就像自己家的门牌号），8188 是端口号（就像楼层的编号）。这句话的意思就是：你的浏览器通过这个地址访问自家电脑上运行的 ComfyUI。以后每次用，都先启动脚本，再访问这个地址。

方式二：手动安装（进阶，可选）

如果你喜欢干净环境，或者打算在 Linux 服务器上跑，可以手动装。需要先装好 Python 3.10~3.12 和 Git，然后执行：

# 1. 克隆 ComfyUI 官方仓库到本地
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI

# 2. 安装 Python 依赖
pip install -r requirements.txt

# 3. 启动（英伟达显卡）
python main.py

# 如果你的显卡显存不大，可以用低显存模式启动
python main.py --lowvram

其他硬件平台对应的启动命令：

# AMD 显卡（Linux 用户）
python main.py --directml
# 苹果电脑（Mac）
python main.py --force-fp16

3.1 第一次启动常见问题速查

现象 最可能原因 处理
双击脚本一闪而过 显卡驱动或 Python 问题 看脚本窗口的报错文字，截图搜解决方案
网页打不开 服务没启动成功，或防火墙拦截 回启动窗口看是否出现了 127.0.0.1:8188 那行
提示 CUDA 相关错误 显卡驱动过旧 更新到 NVIDIA 官网最新驱动
生成特别慢 在 CPU 上跑 确认用的是独显；检查启动参数

如果卡住，最常见的原因就两个：路径里有中文、显卡驱动太旧。先把这两点排查掉。

四、认识界面：菜单、画布与队列

第一次打开 ComfyUI，你可能觉得「这是什么鬼」——一片深色画布，几串连好的小方块。别慌，我们逐个认识。

4.1 顶部菜单

  • Queue（队列）：点击后开始运行当前工作流。快捷键是 Ctrl+Enter。它下面有个「任务进度」，能看当前正在跑第几步；
  • Node Library（节点库）：所有积木的分类目录，按需拖出节点；
  • Workflow（工作流）：新建、打开、保存工作流文件（保存的是 .json 文件，可以分享）；
  • Settings（设置）：偏好设置，新手暂时不用动。

4.2 画布（Canvas）

画布就是中间的大片空白区，所有节点都摆在这上面。常用鼠标操作：

操作 作用
左键拖拽节点 移动积木
从节点右端拖到另一节点左端 连线
滚轮 缩放画布
按住鼠标中键拖动 平移画布
选中节点后按 Delete 删除节点

4.3 队列（Queue）

「队列」背后是这样一个概念：你点一次 Queue，ComfyUI 就把当前画布上的流水线从头到尾执行一遍。多条待执行的流程会排队依次运行。这和第 9 篇的「批量生成」直接相关——跑一百张图，就是往队列里塞一百次任务。

4.4 节点右键菜单

在画布空白处双击，会弹出节点搜索框；在某个节点上右键，能对该节点做删除、复制、绕过（Mute，暂时跳过这一步）等操作。「绕过」特别有用：调试时先跳过某一步看效果。

五、第一个工作流：加载官方示例

ComfyUI 自带几个示例工作流，专门用来证明「安装成功」。我们用它完成第一次跑图。

步骤 1：打开示例

  • 方法 A：在浏览器里点 ComfyUI 界面的 Workflow → Browse Templates（浏览模板），选 SD1.5 或 SDXL 对应模板；
  • 方法 B：手动加载 ComfyUI 安装目录下 web/templates 文件夹里的 .json 文件；
  • 方法 C：把别人分享的工作流 .json 文件拖进浏览器窗口，ComfyUI 会自动打开它。

步骤 2：检查模型

示例工作流里的「Load Checkpoint」节点指向一个模型文件名。如果提示找不到文件，说明你还没下载模型。先把第 2 篇提到的模型下载好，放到指定目录：

ComfyUI/models/checkpoints/

比如把 Realistic_Vision.safetensors 放进去后，回 ComfyUI，在 Load Checkpoint 节点上点击下拉框，选择这个名字。

步骤 3：填写提示词

找到两个写着文字的大框（文本框节点），一个标着 positive（正向），一个标着 negative（负向）。先随便填：

正向：a cute cat, sitting on a chair, photo
负向：blurry, low quality, watermark

负向提示词的意思后面第 4 篇细讲，现在先照抄。

步骤 4：点击 Queue，等待出图

点右上角 Queue（或按 Ctrl+Enter）。你会看到节点开始「动」——有的节点变绿或出现进度条，说明正在执行。几十秒后，一张猫的图片出现在节点图上。

如果你看见图片从「一团模糊」慢慢变清晰，恭喜你，你亲眼看见了第 2 篇讲的「去噪」过程。 这是 ComfyUI 最迷人的瞬间。

步骤 5：保存你的工作流

Workflow → Save，把工作流存成文件。建议给每个做过的工作流命名存档，这是你未来最宝贵的资产——比攒模型还重要。

六、给新手的三个习惯建议

装好了、跑通了，但距离「熟练」还有距离。三个习惯帮你少走弯路：

  1. 每跑通一条流程，立刻保存。改坏了可以随时回退，复现成功经验靠的就是存档；
  2. 一次只改一个参数。改完对比效果，才知道是哪个参数造成了变化。同时改三个，出了问题你根本不知道怪谁；
  3. 报错了先看报错框颜色。ComfyUI 出问题时，相关节点会变成红色，把鼠标放上去能看到错误信息。绝大多数错误是「模型文件路径不对」或「节点连线类型不匹配」——别慌，截图搜索，十有八九是老问题。

七、ComfyUI 的日常操作小技巧

跑过示例之后，再教你几手「日常高频操作」，让使用体验立刻顺滑起来。

7.1 汉化界面

默认界面是英文，很多新手看着发怵。整合包通常自带汉化插件（如 AIGODLIKE-ComfyUI-Translation），在 ComfyUI Manager 里搜索安装，然后在 Settings 里选择中文即可。节点名、菜单都能变成中文，学习压力小一大截。

7.2 常用「轻量节点」先备好

以下节点很小，但几乎天天用：

  • Load Image（加载图片）：图生图、局部重绘的入口；
  • Preview Image（预览图片）：出图先看一眼，满意再保存；
  • Save Image（保存图片）：默认存到 output 目录；
  • Image Size（图像尺寸）：自动读取一张图的宽高，方便按原图比例设定画布；
  • Empty Latent Image（空白画布）：文生图的起点。

7.3 从「图片」反查「参数」

你从网上下载了一张别人用 ComfyUI 生成的图（PNG 格式），它可能内嵌了完整的工作流信息。做法：把这张 PNG 图片直接拖进 ComfyUI 窗口，如果图片带内嵌信息，画布上会自动还原出作者当时用的整个工作流——包括模型、提示词、全部参数。这是「复现教程图」最省事的方法（第 10 篇还会再提）。

7.4 卡死/报错怎么办

  • 界面卡住：刷新浏览器页面即可，正在跑的任务一般不受影响；
  • 节点变红：把鼠标悬停在红色节点上，会显示报错原因；
  • 想完全重置：关闭启动窗口，重新运行启动脚本。

7.5 养成「读图」的习惯

每次出图后，ComfyUI 会把参数保存在图片信息里。你可以把「模型、种子、步数」记进文件名，或者用上面「拖图还原工作流」的方式随时回看。参数即历史，保存即复现。

八、本篇小结

  • ComfyUI 是一个把「画图」变成「搭积木」的可视化工具，节点是积木，连线是插槽，拼出来的一条条流水线叫「工作流」；
  • 相比 WebUI，它更灵活、更省资源、更适合自动化和进阶，是当前本地创作的主流；
  • 安装推荐 Windows 一键整合包，路径不要有中文，启动后浏览器访问 http://127.0.0.1:8188；
  • 界面核心：菜单、画布（节点区）、队列，双击画布出节点，右键节点可管理；
  • 用官方示例工作流跑通第一次出图，并立刻保存工作流；
  • 建立好习惯：及时存档、一次只改一个参数、报错先看红色节点。
