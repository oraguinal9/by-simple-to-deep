第五章 训练超参数：学习率、批次与轮数怎么选

微调不是把数据丢进去就完事。有几个旋钮直接决定"训出来是宝还是废"。本章讲最常用的三个：学习率、批次大小、训练轮数。

学习率（Learning Rate）：迈多大的步子

学习率决定"每次参数更新迈多大步"。它就是你在 L3《梯度下降》里学的那个 lr。

  • 太大：一步跨太远，在损失山谷里来回横跳甚至飞出去（发散），损失不降反升。
  • 太小：步子碎，训练极慢，可能还没学会就到了预算上限。
  • 恰到好处：稳稳走向谷底。

微调的坑在于：底座模型已经训得很好了，它经不起大学习率。所以微调的学习率通常比从零训练小 10~100 倍：全量微调常在 1e-5 ~ 5e-5，LoRA 因为只动小旁路，可以用稍大一点（如 1e-4 ~ 3e-4）。

类比：底座模型像个已经走得很稳的人，你只要轻轻推他转向（小学习率）；别一把将他扛起扔（大学习率），那会摔。

热身（Warmup）

很多训练会先让学习率从 0 慢慢升到目标值（warmup，比如前 3% 步数），再按计划降。这能避免一开始大梯度把小旁路"冲坏"。新手直接用框架默认的 warmup 即可。

批次大小（Batch Size）：一次看几条文

批次大小 = 每步同时算损失、一起更新参数的样本数。

  • 大 batch：梯度估计更稳，训练快（显存允许时），但显存吃紧、单步"见过的样本"多可能略欠灵活。
  • 小 batch：显存友好，但梯度噪声大、训练更"抖"。

消费级显卡显存有限，batch 常被迫设小（如 4、8）。这时框架提供 梯度累积（Gradient Accumulation）：攒 N 个小步的梯度，再统一更新，等效于大 batch，却不爆显存。这是 QLoRA 训练里极常用的技巧。

训练轮数（Epochs）：把数据刷几遍

一个 epoch = 把训练集完整过一遍。轮数太多会过拟合（见第六章）。

微调数据往往很少（几百~几千条），如果只过 1 遍可能学不够；过太多又背下来了。常见区间：

  • 小数据集（几百条）：3~10 个 epoch 起试。
  • 较大数据集（几万条）：1~3 个 epoch 常够。

配合早停（Early Stopping）最稳：盯着验证集损失，它开始回升就停，不硬凑轮数。

一个实用的"起手配置"

新手第一次微调，可以用这组被广泛验证过的默认值开跑，再看损失曲线微调：

参数 LoRA/QLoRA 推荐起点
学习率 2e-4（LoRA）或 1e-4（全量）
rank r 16
alpha 32（=2r）
batch size 4~8（显存不够就开梯度累积）
epochs 3（小数据可到 5~10）
warmup 总步数 3%~10%

记住：先跑通、再看曲线、后调参，比一开始就纠结参数重要得多。能稳定跑完一遍，你已经超过了大多数人。

监控什么？

训练时盯这几个数（下一章细讲）： - train loss（训练损失）：应稳步下降。 - eval/val loss（验证损失）：应跟着降，若回升 = 过拟合信号。 - learning rate：确认 warmup 和调度按预期走。

本章小结

  • 学习率最关键：微调用小学习率（LoRA 可稍大），太大直接发散。
  • batch 受显存限制，用梯度累积等效放大；warmup 保护小旁路。
  • epochs 别贪多，配合早停防过拟合。
  • 先用一套靠谱默认值跑通，再看曲线调参。
