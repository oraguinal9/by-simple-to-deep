第十章 动手实践与进阶路线

十章走完，你已经从"什么是微调"一路摸到了"怎么部署上线"。这一章给你能直接跑的最小实践路径，以及通往更高级玩法的路线图。

最小可跑实践（消费级显卡版）

如果你有一张 24GB 及以下的显卡，想亲手训一个 7B 模型，推荐这条最省心的路：

1. 选底座：一个开源 7B 指令模型（如 Llama-3-8B-Instruct / Qwen2.5-7B-Instruct 等）
2. 备数据：按第四章格式，准备 300~1000 条「指令—输入—输出」配对
3. 上 QLoRA：4-bit NF4 底座 + LoRA(r=16, alpha=32)，学习率 2e-4
4. 训几轮：epochs=3，开 warmup + 梯度累积（batch 不够时）
5. 看曲线：盯 train/eval loss，eval 回升就早停
6. 评估：抽 50 条真实问题人工打分 + 自动指标
7. 量化部署：llama.cpp / vLLM 加载底座+LoRA，起 OpenAI 兼容 API

全程工具链成熟（HuggingFace transformers + peft + bitsandbytes 做 QLoRA，trl 提供高层训练器）。新手不必从零写训练循环，调参数即可。

一段最小代码骨架（示意）

from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig
from peft import LoraConfig, get_peft_model

# 1) 4-bit 量化底座（QLoRA 关键）
bnb = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4")
model = AutoModelForCausalLM.from_pretrained("基座模型名", quantization_config=bnb)
tok = AutoTokenizer.from_pretrained("基座模型名")

# 2) 挂 LoRA 旁路
lora = LoraConfig(r=16, lora_alpha=32, lora_dropout=0.05, task_type="CAUSAL_LM")
model = get_peft_model(model, lora)   # 此时 99% 参数冻结，只训 LoRA
model.print_trainable_parameters()    # 会看到可训练参数仅约 1%

这只是骨架，真正训练还需 Trainer/SFTTrainer 配数据、超参、日志。重点是让你看清"QLoRA + LoRA"在代码里就是这么几行关键点。

常见翻车与排查清单

现象 可能原因 对策
loss 变 NaN 学习率太大 / 有脏样本 降 LR 一个量级，清洗数据
eval loss 回升 过拟合 早停、加数据、降 rank
显存爆了 batch 太大 / 没量化 开 4-bit、降 batch + 梯度累积
输出乱码 数据与底座格式不符 统一对话模板
训完没变化 数据量太少 / LR 太小 加数据、调大 LR
部署巨慢 引擎没优化 换 vLLM/llama.cpp

进阶路线（学完 L1–L5 之后）

  • L6 RLHF：用"人类反馈强化学习"让模型更对齐人类偏好（比 SFT 更上层）。本系列下一阶。
  • 更小/更大模型：试 3B（边缘部署）与 70B+（需多卡/量化）的权衡。
  • 多 LoRA 路由：一个底座按场景动态加载不同适配。
  • 评测体系化：建自己的 benchmark，持续回归。
  • Agent 化微调：让模型既懂知识，又会用工具（结合 L4）。
